## 怎么用

1. 每遇到一个 mint 机会，按 CHECKLIST.md 逐条过。
2. 「必须满足」任何一条**未知**，都算不通过。
3. 「一票否决」命中任何一条，直接放弃。
4. 「继续观察」只能把项目降级为观察，不能当作放行理由。
5. 金额、频率、gas 等上限请按自己的风险承受能力自行设定，本表不提供具体数值。
