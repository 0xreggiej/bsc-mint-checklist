## 范围

本仓库只发布规则文档，不包含钱包连接、签名或交易实现。规则通过不等于交易授权：能否执行，以使用者另行写明的授权（链、钱包、动作、金额 / gas / 频率上限、有效期）为准；必要参数未配置时只做研究，不能由 agent 自行填写。逐版本差异请看 Git 提交历史。

## 怎么用

1. 每遇到一个 mint 机会，按 CHECKLIST.md 逐条过。
2. 「必须满足」任何一条**未知**，都算不通过。
3. 「一票否决」命中任何一条，直接放弃。
4. 「继续观察」只能把项目降级为观察，不能当作放行理由。
5. 金额、频率、gas 等上限请按自己的风险承受能力自行设定，本表不提供具体数值。
