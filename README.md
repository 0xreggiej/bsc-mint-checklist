# BSC Mint 检查表

用于 BNB Smart Chain 上 Binance Agentic Wallet / Agent ID（.ai）相关第三方 mint 候选的发现、核实和准入判断。

- 日期：2026-10-31。
- 项目类型：公开的规则文档与记录模板，不是自动交易软件；不包含监听器、钱包连接或交易执行实现。

## 适用对象与用途

面向研究 BNB Chain 第三方 mint 项目的个人与开发者，帮助整理候选来源、核实关键证据并记录准入结论。开发者可参考这些约束设计只读研究工具，但仍需独立实现、测试和验证。

热度、研究优先级和手动指定不能替代检查表中的风险条件，也不能授予交易权限。本项目是社区整理的检查规范，非 Binance 官方产品，不代表对任何代币、NFT 或工具的推荐。

## 使用顺序

1. 参考 DISCOVERY 手动整理候选、来源和数据覆盖范围；仓库文档本身不会启动采集。
2. 按 CHECKLIST 逐条核实，保留全部命中原因。未知、不满足、观察或否决均不能执行。
3. 单独记录研究优先级，不将其作为交易评分。高热度也不能覆盖未知或否决。
4. 文档和模板均不授予钱包权限；任何执行动作须另行获得钱包持有人的明确授权，并满足执行前复核条件。

风险阈值、永久否决和退出规则以 CHECKLIST 为准，不因新增发现方法而放宽。必要参数须由使用者配置；缺失时仅可研究，不得自动执行。规则不保证收益。逐次差异请查看 Git 提交历史。
